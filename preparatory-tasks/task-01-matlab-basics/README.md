# Preparatory Task 1 — MATLAB Array & Vector Basics

Warm-up exercises before Session 1, covering array indexing, concatenation, and basic plotting commands.

## Covers
- Indexing and slicing a matrix (`a(2,3)`, `a(2,:)`, `a(:)`, etc.)
- Logical comparisons on arrays (`a == 5`, `a > 5`)
- Building matrices with `zeros`/`ones`
- The colon operator for ranges (`0:0.5:3.2`)
- Deleting elements from a vector
- Matrix arithmetic: transpose, elementwise (`.*`, `.^`) vs matrix (`*`, `^`) operators
- `stem` vs `plot` for discrete/continuous signals, and `conv` for convolution
