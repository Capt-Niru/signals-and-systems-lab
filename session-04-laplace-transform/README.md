# Session 4 — Laplace Transformation

Using MATLAB's Symbolic Math Toolbox and Control commands to find Laplace/inverse Laplace transforms, poles/zeros, time responses, and Bode plots.

## Covers
- `laplace` / `ilaplace` for forward and inverse transforms
- `residue` for partial fraction expansion
- `roots` for poles/zeros of a transfer function
- `impulse` and `step` for time-domain responses
- `bode` for frequency response and stability commentary
