# Session 3 — Convolution

Exploring the convolution integral/sum, and how an LTI system's output is its impulse response convolved with the input.

## Covers
- Convolving two finite discrete sequences with `conv`
- Deconvolution: recovering `h[n]` given `X[n]` and `Y[n] = X[n]*h[n]`
- Continuous-time impulse response `h(t) = (1/4)(e^{-2t} - e^{-t})` driven by `cos(t)u(t)` and `sin(t)u(t)`
- Discrete LTI system with `h[n] = (0.6)^n u[n]`, driven by a step and a cosine input
