# 📡 Signals and Systems — Lab Journey

> Hands-on MATLAB/Octave work for the **Signals and Systems** course at the Open University of Sri Lanka (BSc Computer Engineering).

This repo is where I'm documenting my lab sessions, preparatory tasks, and mini project as I work through the course — not just to submit assignments, but to actually build intuition for how signals move through systems in the time, frequency, and Laplace domains.

---

## 🎯 Why this repo exists

Signals and Systems is one of those subjects where the math only clicks once you *see* it — a convolution integral means very little until you watch two signals slide past each other and plot the result. This repo is my public lab notebook: every session's code, plots, and the "aha" moments along the way.

Each session folder contains:

- `plots/` — exported figures from running the script

## 🚀 How to run

1. Clone this repo:
   ```bash
   git clone https://github.com/<your-username>/signals-and-systems-lab.git
   ```
2. Open any session folder in MATLAB or Octave.
3. Run the `.m` script — plots will pop up and also get saved into that session's `plots/` folder.
